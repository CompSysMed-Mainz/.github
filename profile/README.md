# Computational Systems Medicine (CTH / Cardiology - University Medical Center of the JGU Mainz)

This is the GitHub organization for the Computational Systems Medicine group of the Center for Thrombosis and Hemostasis (CTH) and the Dept. of Cardiology, University Medical Center of the Johannes Gutenberg University Mainz.

Members:
- Vincent ten Cate, group leader
- Harsini Raaja Sulochana, PhD student
- Yufan Yang, PhD student
- Ayesha Sanober, PhD student

We do:
- Multi-omics analyses with a focus on cardiovascular disease and aging

This Github organization is for:
- Code review within our group
- Sharing code internally
- Hosting code for published analyses publicly
